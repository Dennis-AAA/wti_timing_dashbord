# 黄金与原油瘦身双核策略互动网页看板 (离线完整版)

## 包含文件
1. `gold_oil_slimmed_signals_dashboard.html` / `index.html`: 零外部依赖单文件互动看板（支持双击直接在浏览器打开或部署至 GitHub Pages）。
2. `gold_low_disp5_backtest.csv`: 黄金 (GC) 2021-01-04 至 2026-10-22 逐日价格、60日IV离散度分位、信号灯与持仓状态序列。
3. `crude_oil_high_disp20_weaktrend_backtest.csv`: 原油 (CL) 2021-01-04 至 2026-10-22 逐日价格、60日IV离散度分位、T20趋势强度、信号灯分类与多门槛持仓状态序列。

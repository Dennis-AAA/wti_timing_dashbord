# WTI原油期货 (CL) 实证信号交互看板 (2014–2026)

本压缩包由《WTI原油期货多头退出机制、期权Greeks信号检验与系统化做空策略深度研究报告》中的原油多空实证信号互动看板提取构建，提供**单文件即开即用版**与**模块化源码工程版**两种结构。

## 目录结构

- `wti_crude_oil_dashboard.html`：**单文件自包含完整互动网页**（双击即可在任意浏览器离线/在线打开，无需本地服务器）。
- `index.html`：模块化工程入口页面（引用 `css/` 与 `js/` 目录）。
- `css/styles.css`：看板暗色金融终端主题样式表。
- `js/data.js`：2014–2026 年 WTI 原油主力连续价格、5日均线、30D ATM 隐含波动率、60D 五节点离散度及全部 71 笔实证交易信号数据集。
- `js/app.js`：双面板 Canvas 高分屏联动渲染引擎、时间窗口/信号图层过滤器、单笔交易显微镜及 CSV 导出控制器。
- `data/wti_signals_2014_2026.csv`：全部 71 笔实证信号标准 CSV 数据表（UTF-8-SIG 编码，可直接用 Excel 打开）。

## 核心交互功能

1. **五维时间窗口切换**：全周期 (2014–2026)、2014–2019 早期样本、2020–2022 疫情与通胀周期、2023–2024 震荡期、2025–2026 样本外大考。
2. **四类实证信号图层叠加与过滤**：
   - `▼ Q3 顶部右侧做空 / 止盈`（18笔，净损益 +$68,577，胜率 72%）
   - `▲ Q1 恐慌抄底 + 三重障碍退出`（24笔，2ATR自适应+重置）
   - `◆ Q2 突破续涨 + 止盈退出`（19笔，Q1+Q2 合计 43笔净损益 +$192,740，胜率 93%）
   - `✖ IV60 窄止损3%错杀诊断`（10笔典型解剖样本，展示 0.66x ATR20 噪音洗盘与 2026 样本外 5 笔止损微观对比）
3. **双面板同步十字线与交易显微镜**：在主图点击任意信号标记或在下表点击任意行，即可联动展示该笔交易的开平仓价格、期权分位指标、单手净损益及 20 日 MFE/MAE 风险路径。
